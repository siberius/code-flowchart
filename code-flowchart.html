Základní syntaxe v bloku AKCE

x = 5
Přiřazení čísla
jmeno = "Jana"
Přiřazení textu v uvozovkách
soucet = a + b
Aritmetické sčítání (též - * / % **)
x++ nebo x--
Zvýšení / snížení o jedna
x += 3
Zkrácený zápis pro x = x + 3

Podmínky a Smyčky

== (Rovná se), != (Nerovná se)
> (Větší), >= (Větší nebo rovno)
< (Menší), <= (Menší nebo rovno)
x > 0 && x < 10
Logické AND (A zároveň)
x < 0 || x > 10
Logické OR (Nebo)
⚠️ Uvnitř podmínky nesmí být znak = bez ! < >. Linter by to odhalil jako chybu.

Práce se Vstupy a Výstupy

VSTUP: Do bloku napiš pouze název proměnné (např. vek). Po spuštění se zobrazí okno pro zadání.
VÝSTUP: Můžeš psát text a vkládat proměnné do složených závorek. Např.: Máš {skore} bodů.
Přepínání Vstup/Výstup: Klikni na malou ikonku kolečka přímo uvnitř fialového bloku.

ℹ️ O programu

CodeFlowChart EDU je moderní, plně interaktivní výukový nástroj navržený pro snadné a vizuální pochopení logických struktur, algoritmů a stavových proměnných. Spojuje návrh vývojových diagramů s krokovacím enginem a Visual RAM pamětí v reálném čase.

Tato aplikace slouží jako ukázka pokročilé SPA (Single Page Application) architektury. Je kompletně obsažena v jediném HTML souboru a byla vytvořena za asistence umělé inteligence Google Gemini 3.1 Pro v roce 2026.
